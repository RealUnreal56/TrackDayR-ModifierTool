# ModifierTool

ModifierTool is a Windows application for modifying **TrackDayR** game files.

It allows you to edit various properties of bikes and create, save, and load your own modifications without manually editing the game files.

## Features

* 🏍️ Modify bike engine parameters
* ⚙️ Modify gearbox and drivetrain settings
* 🔊 Change engine sounds
* ✏️ Edit bike in-game names
* 💾 Save and load modifications
* 🔄 Easily share modifications with others
* 🖥️ Simple and modern Windows interface
* 🔔 Automatic update detection

## Installation

Download the latest release from the [Releases](https://github.com/RealUnreal56/TrackDayR-ModifierTool/releases) page.

Download the latest `ModifierTool.zip`, extract it, and launch:

```text
ModifierTool.exe
```

The application is self-contained, so no separate .NET installation is required.

## First Launch

On the first launch, ModifierTool will ask you to select your **TrackDayR mod folder**.

This is the folder containing your TrackDayR mod files, such as:

```text
bikes
tracks
cosmetics
```

Once selected, ModifierTool can access these files and allows you to modify your TrackDayR content.

## Saving Modifications

Modifications can be saved as separate files and loaded again later.

This allows you to:

* Keep different setups for the same bike
* Swap modifications between bikes
* Back up your modifications
* Share your modifications with other players
